Bước 1

Chọn file tỷ giá

File .csv có dòng tiêu đề, gồm cột ngày và cột tỷ giá (ví dụ Ngày,Tỷ giá). Excel: chọn File → Save As → CSV UTF-8.

Tỷ giá USD/VND chuyển khoản Vietcombank, 28/10/2021 – 28/10/2026, 1.247 ngày.
Bước 2

Thiết lập và chạy

Chạy dự báo · khoảng 1–3 phút · 1 lần chạy GA/SA, ngân sách 30 cấu hình, 3 fold. Mỗi lần bấm Chạy, mọi mô hình được tính mới từ đầu, không dùng kết quả có sẵn. Kết quả để minh họa, không dùng để so với số liệu chính của bài.
